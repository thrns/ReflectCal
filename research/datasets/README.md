# Dataset foundation

The M0 fixture set is generated by `src/lib/experiments/dataset/generator.ts` with seed `20261110`. It contains fixed arithmetic and elementary probability questions. Correct answers are computed by the generator, not generated or graded by Gemini. IDs are stable; each fixture belongs to exactly one of the `research` or `playground` splits.

Regenerate the checked-in JSON fixture and local Supabase seed SQL with:

```sh
bun run dataset:generate
bun run dataset:validate
```

The public API returns only validated `playground` questions and strips the answer key and split metadata. `research` questions remain on the server and in the privileged database.

`adapters.ts` defines the future normalization contract. An MMLU-Pro adapter is not implemented or downloaded in M0. A later adapter should pin an exact upstream release, retain question IDs and subject metadata, verify its license and answer keys, and assign disjoint splits before any question reaches the public endpoint.
